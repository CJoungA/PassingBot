# Passing Bot 0.5

Unity project prepared for GitHub.

## Requirements

- Unity 2021.1.17f1

## Project Layout

- `Assets/` - game assets, scenes, prefabs, materials, and scripts
- `Packages/` - Unity package manifest and package lock file
- `ProjectSettings/` - Unity project settings

## Opening the Project

1. Open Unity Hub.
2. Add this folder as a project: `PassingBot-0.5`.
3. Open it with Unity `2021.1.17f1`.
4. Let Unity regenerate `Library/`, IDE project files, and other local cache folders.

## Git Notes

Generated Unity folders such as `Library/`, `Temp/`, `obj/`, `Logs/`, and `UserSettings/` are ignored by `.gitignore`.
